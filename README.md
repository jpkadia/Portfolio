# Portfolio Project (Fullstack: Frontend + Backend)

Yeh project 2 distinct folders me structured hai:
1. `backend/` - Node.js + Express + MongoDB Atlas contact form API
2. `frontend/` - React application

---

## 🚀 Kaise Run Karein

### 1. Backend Start Karna
Ek terminal me run karein:
```bash
cd backend
npm start
```
> Server `http://localhost:5000` par run hoga aur MongoDB Atlas cluster se connect ho jayega.

### 2. Frontend Start Karna
Doosri nayi terminal me run karein:
```bash
cd frontend
npm start
```
> React app `http://localhost:3000` par open ho jayega.
